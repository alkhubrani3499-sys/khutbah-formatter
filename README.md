# منسّق الخطب

موقع يستقبل نص خطبة الجمعة بلا تشكيل، فيضبطه بالشكل (كامل أو وظيفي)، ويصحّح الأخطاء الإعرابية الصريحة فقط، ويحوّل الآيات إلى الرسم العثماني (مصحف المدينة – حفص)، ثم ينسّقه ويصدّره PDF أو Word بمقاس A4 أو الجوال، ملوّناً أو بالأسود.

## التشغيل

```bash
npm install
npm run setup:data      # تنزيل نص المصحف (Tanzil) والخطوط وبناء جدول المطابقة
cp .env.example .env.local   # ثم ضع ANTHROPIC_API_KEY
npm run dev
```

يتطلب توليد PDF وجود Chrome أو Edge على الخادم (يُكتشف تلقائياً، أو اضبط `CHROME_PATH`).

## كيف يضمن عدم تغيير النص؟

1. يُرسل النص إلى Claude (`claude-opus-5-5`) مع تعليمات صارمة: إضافة الحركات فقط، ووسم الآيات والأحاديث والنداءات، وتسجيل كل تصحيح إعرابي في قائمة مستقلة.
2. يقارن الخادم كل كلمة في الناتج بأصلها حرفاً بحرف بعد حذف الحركات. أي كلمة تغيّرت حروفها دون أن تكون تصحيحاً مسجَّلاً (في حدود حرفين) **تُعاد إلى أصلها**، وأي كلمة حُذفت تُعاد، وأي كلمة أُضيفت تُحذف. علامات الترقيم تؤخذ من الأصل دائماً.
3. الآيات تُطابَق مع قاعدة بيانات المصحف وتُستبدل بنصها العثماني الحرفي؛ وما لا يطابق يبقى كما كتبه الخطيب مع تنبيه. وتُكتشف كذلك الآيات غير المعلَّمة (٥ كلمات متتالية فأكثر مطابقة للمصحف).
4. يعرض الموقع قائمة التصحيحات الإعرابية والملاحظات ليراجعها الخطيب.

## البنية

| الملف | الدور |
|---|---|
| `lib/server/llm.ts` | استدعاء Claude بإخراج منظَّم (JSON Schema) |
| `lib/server/process.ts` | تقسيم النص، المعالجة المتوازية، المطابقة وحماية النص |
| `lib/server/quran.ts` | فهرس المصحف ومطابقة الآيات |
| `lib/render.ts` | محرك الصفحات (المعاينة و PDF) مع فواصل ذكية للجوال |
| `lib/server/docx.ts` | توليد Word بخطوط مضمَّنة (Amiri / Amiri Quran) |
| `app/api/export/pdf` | Puppeteer يطبع صفحة `/print` بالمحرك نفسه |
| `scripts/selftest.ts` | اختبار ذاتي بلا نموذج: `npx tsx scripts/selftest.ts` |
